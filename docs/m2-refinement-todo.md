## 6. 语音输入与自然、亲切的朗读

交互方向：用户点击录音 → 转成可编辑文字 → 检查后发送 → 使用现有 Agent 回复 → 按需点击朗读。

2026-11-02 已确定使用阿里云百炼，语音输入与按需朗读分两步验收。2026-11-03 登录用户语音输入首版已实现，使用 `qwen3-asr-flash` 同步 HTTP 接口；录音/上传隔离检查及真实浏览器 WebM 的云端识别通过，真人麦克风完整页面链路待单独确认。回复朗读使用 `cosyvoice-v3-flash` 与龙安欢 `longanhuan`，用户已反馈真实前后端联调成功；首次点击播放时合成，页面保留音频供再次播放，文本或音色改变后需重新合成。详细范围见[语音验证记录](m2-speech-verification.md)。

识别接口通过后端 `RestClient` 调用 OpenAI 兼容 HTTP 地址，支持 Base64 Data URI；浏览器 WebM/Opus 录音在官方支持列表内，具体输出格式仍需浏览器实测。新接入配置北京业务空间 API Host 和同地域 API Key，参考[识别 API](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[音频规格](https://help.aliyun.com/zh/model-studio/asr-model)、[龙安欢音色](https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list)及[合成 HTTP API](https://help.aliyun.com/zh/model-studio/cosyvoice-tts-http-api)。

预算按北京 Flash 合成 1 元/万计费字符、识别 0.00022 元/秒估算，不扣免费额度或活动优惠；中文每字暂预留 2 个计费字符仅用于保守预算，接入后以 `usage.characters` 与账单校准。定价来源为[官方价格表](https://help.aliyun.com/zh/model-studio/model-pricing)，不把预算假设作为实际计费规则。
