# M2 语音输入与回复朗读验证记录

日期：2026-11-03。

## 当前实现

- 登录用户点击“语音输入”，允许麦克风后录音，停止后识别；游客点击时打开登录窗口。
- 最长60秒、最大5MiB。优先使用浏览器 WebM/Opus，兼容 Ogg；不支持录音、格式或权限时保留文字输入。
- 结果追加到输入框，用户可修改并手动发送；不会自动调用 Agent 或确认订单。
- 录音开始后原文有修改，识别结果单独展示供插入或丢弃；合并超过2000字时保留完整结果，禁止直接插入，不静默截断。
- 录音或识别期间禁用发送；取消、切换账号、新对话、离开点餐页会停止设备或丢弃迟到响应。页面隐藏时取消活动录音/识别，已完成的候选文字仍保留。
- 麦克风在停止、取消、错误、超限及设备断开后释放；被取消的权限请求迟到时，也释放其返回设备。

## 文件职责

- `speech-recorder.mjs`：浏览器设备、音频片段、60秒/5MiB上限及资源清理。
- `speech-client.mjs`：FormData 上传，不手写 multipart Content-Type，不重试。
- `speech-input.mjs`：页面状态、身份/会话快照、识别请求取消、文本回填和候选。
- `agent.js`：与现有输入框、会话、登录和页面切换接合。

## 后端契约

`POST /speech/recognize`，请求类型为 `multipart/form-data`，文件字段为 `audio`，携带 `X-User-Token`。成功响应：

```json
{"code":0,"msg":"success","data":{"text":"识别出的文字"}}
```

模型为 `qwen3-asr-flash`。`ALIYUN_SPEECH_BASE_URL` 须包含 `https://` 且仅填北京业务空间域名，`DASHSCOPE_API_KEY` 使用同地域凭证，密钥只保存在后端。

单文件限制5MB、总请求6MB；全局异常分别处理缺字段400、上传超限413、请求类型不支持415。Tomcat `max-swallow-size: 8MB` 用于覆盖本次略超6MiB请求的错误回送，并不放宽上传允许值，也不保证任意超大请求均返回完整JSON。Redis配置仍属于 `spring.data.redis`。

## 回复朗读：首版基础链路已通过真实联调

- 完成回复后显示朗读按钮，首次点击请求合成，音频下载为页面内Blob后供停止与重播复用。开始录音会停止朗读或取消等待合成；换账号、新对话清理缓存并撤销对象URL。
- 普通回复去除Markdown、URL和草稿UUID；有效报价和订单使用后端结构化数据生成朗读摘要。下单明确拒绝时读取工具失败说明；结果未核实时只读待核实提示，查到真实回执后更新朗读并清理旧音频。
- 前端使用 `speech-text.mjs`、`speech-synthesis-client.mjs`、`speech-playback.mjs`，通过 `agent.js` 与现有回复及录音交互连接。
- 约定接口：`POST /speech/synthesize`，携带 `X-User-Token`，JSON请求仅为 `{"text":"待朗读文字"}`；前端最多提交1000字符，模型和音色从后端配置读取。
- 成功响应约定：`{"code":0,"msg":"success","data":{"audioUrl":"https://音频地址","model":"cosyvoice-v3-flash","voice":"longanhuan"}}`。下载音频时不携带登录凭证；重复播放不重复合成，下载失败时再次点击先复用已获得的合成地址。
- 25项隔离浏览器检查通过，覆盖单次生成与重播、登录/旧401、取消/迟到、单音频、录音互斥、浏览器播放手势、错误响应、文本清洗、真实报价及320/390布局。
- 另4项针对性检查通过：明确工具拒绝覆盖模型误报、核实成功后撤销旧音频并更新朗读、为已核实的中断回复新增朗读，以及已支付状态的中文表达。原有45项前端单元测试、26项订单核实回归也已复测通过。
- 请求/响应DTO、Service及Controller已实现，JSON参数绑定、非空/1000字符校验和登录鉴权已接通。Service包含HTTP调用、响应校验、HTTPS地址规范化和DTO返回，非法配置与上游异常统一为合成服务503。编译和42项临时本地HTTP隔离检查通过，包括请求契约、1000字符边界、JSON/URL错误、上游401/403/429/500、配置缺失/非法及连接失败；这些隔离检查未调用云端或数据库，临时脚本和HTTP服务已清理。
