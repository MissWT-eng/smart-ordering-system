## 在其他环境使用

1. 准备好当前 `dish` 表，包含 `dish_number` 自增主键，以及名称、状态、介绍、价格、分类和辣度列。
2. 在对应数据库执行 SQL 种子。此文件为新增 60 道的增量数据，不包含原有 21 道菜单或建表语句。
3. SQL 导入不会自动生成向量。启动 Qdrant 与应用并配置向量化凭证后，可使用现有商户接口 `POST /admin/dishes/vector/resync` 重建索引；需携带有效 `X-Admin-Token`。该接口会清空并按数据库全部在售菜品重建集合，本轮实际同步采用了仅追加新菜向量的方式。

种子 JSON、SQL 和数据库中的新菜均保留。临时导入、核对和向量查询辅助程序在完成后清理。
